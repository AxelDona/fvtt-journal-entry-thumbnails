# Journal Entry Thumbnails

A small, system-agnostic [Foundry VTT](https://foundryvtt.com/) module that lets the GM assign any image as a thumbnail to a journal entry. The thumbnail is shown next to the entry's name in the Journal sidebar, so your handouts, NPCs, locations and lore are easier to tell apart at a glance. The image used for the thumbnail is independent of the entry's content.

![Foundry v13](https://img.shields.io/badge/Foundry-v13-informational) ![Foundry v14](https://img.shields.io/badge/Foundry-v14-success)

## Usage

1. As the GM, open a journal entry.
2. Click the **⋮** button in the window header.
3. Choose **Set Thumbnail** and select an image.
4. The thumbnail now shows in the Journal sidebar. Use **Delete Thumbnail** in the same menu to remove it or **Set Thumbnail** to change it.
